Données personnelles

Confidentialité

Voici les données utilisées par les fonctionnalités actuelles de ce site.

Pas de compte ni de formulaire

Le site ne propose actuellement ni compte utilisateur, ni formulaire de collecte, ni outil de mesure d'audience. Si vous choisissez d'écrire à l'adresse de contact, les informations que vous transmettez sont utilisées pour répondre à votre message.

Préférence d'animation

Lorsque vous modifiez le réglage des animations, le site peut enregistrer votre préférence dans le stockage local de votre navigateur sous la clé « animations ». Cette donnée reste sur votre appareil, n'est pas transmise au site et peut être supprimée en effaçant les données de navigation.

Ressources externes

Les pages chargent les polices Google Fonts et les scripts GSAP depuis des services tiers. Le navigateur contacte ces fournisseurs pour récupérer les ressources demandées ; ces requêtes sont soumises à leurs propres politiques de confidentialité. Aucun outil analytique n'est intégré au site.

Vos questions

Pour toute question concernant la confidentialité ou un message que vous avez envoyé, vous pouvez contacter l'éditeur à l'adresse thomas.fer@free.fr.
